Open-Source Wallpaper Engines

A curated collection of open-source wallpaper engines for developers. This repository's own effect engine and demo code are fully open — study them, remix them, and share feedback below.

MacWall-desktop Effect Engine Particle effect engine (effects.js) and macOS window demos — this repository, open source Lively Wallpaper Open-source animated desktop engine for Windows (GIF / video / web) WinDynamicDesktop Dynamic wallpapers on Windows (macOS Dynamic HEIF scheme) dynamic-wallpaper Dynamic wallpaper scripts for Linux (GNOME / KDE) playground-macos macOS desktop in the browser (source of this repo's Dock icons, MIT) macos-web macOS desktop in the browser (MIT)
